# 🎓 Integrated Campus Management System

An **Integrated Campus Management System** built to efficiently manage all aspects of a college/university campus — including **Students**, **Faculty**, and **Administrative** tasks.

This project combines modern backend development with traditional web technologies for a robust campus management solution.

---

## ✨ Key Features

- **Student Management** — Add, view, update, and manage student records
- **Faculty Management** — Manage faculty profiles, departments, and assignments
- **Administrative Tasks** — Handle campus-wide operations and reports
- **Role-based Access** — Separate views/modules for Students, Faculty, and Admin
- **Database Integration** — Full CRUD operations with relational database
- **User-friendly Interface** — Responsive web UI for easy navigation

---

## 🛠️ Technologies Used

- **Backend**: Spring Boot (Java)
- **Frontend**: PHP (with HTML, CSS, JavaScript)
- **Database**: MySQL (via XAMPP)
- **Build Tool**: Maven (for Spring Boot)
- **Server**: Apache Tomcat (embedded in Spring Boot) + XAMPP (for PHP/MySQL)

> This is a **hybrid** project that integrates **Spring Boot** (RESTful backend) with **PHP** (frontend or additional modules).
